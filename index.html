Pasar los datos de un aparato a otro

La app guarda todo dentro de este navegador. El celular y la computadora no se hablan entre sí: cada uno tiene su propia copia. Para pasar lo del celular a la compu (o al revés): Copiar backup en el aparato que tiene los datos buenos, te lo mandás por WhatsApp o mail, y Pegar backup en el otro.

FechaProductoCant.PrecioTotal
Hacé backup una vez por semana. Si borrás los datos del sitio o cambiás de celular, sin backup los perdés. Las ventas marcadas como estimado (abril-mayo) no son ventas cargadas una por una: se reconstruyeron desde las bolsitas compradas para que el total cierre.
